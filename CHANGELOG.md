# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-03-20

- Add image-based job import from pasted screenshots or selected files
- Reuse AI provider settings for visual parsing
- Add clipboard image import support
- Update docs and privacy notes for image import workflow

## [0.1.0] - 2026-03-20

- Initial public open-source release
- Capture BOSS job detail pages into a side panel queue
- Support drag-and-drop sorting and inline field editing
- Export saved jobs as Markdown or JSON
- Add optional AI-based JD formatting with OpenAI-compatible and Anthropic endpoints
- Add release packaging script and end-user installation documentation
