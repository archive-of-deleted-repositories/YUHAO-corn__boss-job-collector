# BOSS Job Collector v0.2.0

这一版加入了图片导入能力，适合把聊天截图、岗位截图或保存下来的 JD 图片直接导入扩展。

## 新增内容

- 新增 `Image` 导入入口
- 支持粘贴截图导入
- 支持选择本地图片文件导入
- 使用视觉模型识别岗位标题、公司、地点、JD 和链接
- 复用现有 AI 配置，不需要额外设置第二套模型参数

推荐用法：

- 优先使用剪贴板粘贴截图
- 选择本地文件仅作为备用方案

## 安装

1. 下载本页附件 `boss-job-collector-v0.2.0-unpacked.zip`
2. 解压压缩包
3. 打开 `chrome://extensions`
4. 开启右上角 `Developer mode`
5. 点击 `Load unpacked`
6. 选择解压后的文件夹

注意：选择的文件夹里必须直接包含 `manifest.json`。

更详细说明见 [安装文档](install.md)。

## 使用提醒

- `Image` 导入依赖你在扩展内配置的 AI 服务
- 使用截图导入时，图片会发送到你配置的模型服务进行识别
- 从稳定性上看，剪贴板粘贴通常比本地文件上传更稳
- 默认数据仍然只保存在本地浏览器

完整说明见 [PRIVACY.md](../PRIVACY.md)。
